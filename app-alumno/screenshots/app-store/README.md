# Capturas para App Store

Las capturas se exportaron en formato PNG, en orientación vertical y con una
de las dimensiones aceptadas:

- `1242 × 2688 px`
- `1284 × 2778 px`

La imagen de origen era de `1179 × 2556 px`; el contenido se conservó y sólo se
reescaló para cumplir las dimensiones de entrega.

Archivos:

- `01-horario`
- `02-perfil`
- `03-inicio`
